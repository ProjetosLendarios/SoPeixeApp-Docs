# SoPeixeApp-Docs

Documentação e site oficial do SoPeixeApp - O aplicativo definitivo para peixívoros e amantes do aquarismo.

## 🐠 Sobre o Projeto

Este repositório contém a documentação e o site do SoPeixeApp, incluindo:

- **Página Principal**: Apresentação do aplicativo e suas funcionalidades
- **Política de Privacidade**: Informações sobre como tratamos os dados dos usuários

## 🚀 Como Visualizar Localmente

Para visualizar o site localmente, você pode:

1. Abrir os arquivos HTML diretamente no navegador
2. Ou usar um servidor local simples:

```bash
# Com Python 3
python -m http.server 8000

# Com Node.js
npx http-server
```

Depois acesse `http://localhost:8000` no seu navegador.
